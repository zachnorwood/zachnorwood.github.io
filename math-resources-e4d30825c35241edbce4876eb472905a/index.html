Getting started

I just want to create accessible PDFs with LaTeX. How do I do that?

  1. Update your TeX distribution to TeX Live 2026 or equivalent, or select TeX Live 2026 in Overleaf. Installation details.
  2. Add this before \documentclass: 
    \DocumentMetadata{
  lang = en-US,
  pdfversion = 2.0,
  tagging = on,
  pdfstandard = ua-2,
  tagging-setup = {math/setup=mathml-SE, math/alt/use}
}

    This uses the current tagging interface. PDF version and standards explained below. math/alt/use is a compromise for Ally; see the accessibility tradeoff.
  3. Remove or replace unsupported packages or document classes if needed. Compatibility details and troubleshooting.
  4. Compile with LuaLaTeX. You may need to change font-loading commands written for pdfTeX. Fonts and compiler details.

For document-specific details, see table headers, figures and alternative text, section headings, and the PDF title. You can also copy or download a full example document.

For questions about the auto-checker, see Canvas and Ally scores.

Context and choosing a format

What is going on?

University digital content must meet accessibility standards, specifically WCAG 2.1 A and AA. Right now, the big priority is to make digital teaching materials compliant. As of October 2026, UNL’s FAQ gives April 26, 2027 as the revised Title II deadline and says digital content must meet the standards as soon as practical. See the FAQ for policy details.

Math faces unique challenges here, because of mathematical formulas. Luckily, the good folks at The LaTeX Project have done a lot of work to make accessible PDFs possible. And many good options exist for embedding accessible math formulas in HTML pages.

In math, why do we use PDFs?

  • To render mathematical formulas nicely.
    • This can also be done by MathJax etc.
  • To create final-form digital paper documents suitable for long-term archiving.
    • For documents meant for students, the difficulty of creating an accessible version probably outweighs the small benefit of archival quality.
    • PDF-as-digital-paper was designed for sighted people.
      • E.g. artifacts (e.g. page numbers), glue space used by TeX, content order vs reading order.
      • A PDF is just a set of printing instructions that a PDF reader can render as digital paper. It is meant for sighted people.

LaTeX

Setup details and choosing a format

First, be warned that this might not be the easiest option, in every case. If you have a document that contains few or no mathematical formulas but many lists, tables, etc. (I’m thinking particularly of a syllabus here!), then you will probably save yourself a headache by composing it directly in Canvas or (heaven forfend!) as a Word document.

But simple LaTeX documents can be made accessible, with few headaches! Here is an overview of what you must do:

Use an up-to-date TeX installation. Install TeX Live 2026 (or an equivalent distribution based on it), or select TeX Live 2026 in Overleaf, which handles the installation for you. Then keep it current: tagging support changes with LaTeX releases. For example, ltx-talk requires LaTeX 2025-11-01 or later. To update all installed packages and the package manager itself, run: 

tlmgr update --self --all

For a system-wide installation that requires administrator permissions, use sudo tlmgr update --self --all. For a targeted update, use tlmgr update package-name. These commands update packages within your current TeX Live release; they do not upgrade an older annual release (such as TeX Live 2025) to TeX Live 2026. See the TeX Live Manager documentation.

Minor edits to your LaTeX code will be necessary, summarized here: https://latex3.github.io/tagging-project/documentation/prototype-usage-instructions

Major edits might be necessary if your document uses document classes or packages that are not (yet) supported by the tagging project: https://latex3.github.io/tagging-project/tagging-status/

For new documents, compile with LuaLaTeX, if possible. LuaLaTeX ships with all standard TeX installations. Make sure you are not loading font packages specific to pdfTeX when you compile with lua. See the code in the Overleaf template for an example of how to change the font.

Something breaks when I try to load my favorite LaTeX class / package.

Take a look at the classes and packages supported by the tagging project: https://latex3.github.io/tagging-project/tagging-status/

Even very popular packages like amsmath and amsthm have been only partially supported, so check the status page for the current state of anything you load.

In trying to generate tagged PDFs, I'm getting an error in compilation that looks like this: "The number of automatic begin and end text-unit para hooks differ!"

In most other cases I've looked at, an error like this seems to be caused by loading a package that is not fully compatible with the tagging module. Those are listed here: https://latex3.github.io/tagging-project/tagging-status/.

The full error may read: 

Package tagpdf error:
The number of automatic begin (number) and end (different number)
text-unit para hooks differ!

In addition to unsupported classes or packages, bugs in the tagging module can cause problems. After updating your distribution and checking package compatibility, search the tagging project’s GitHub issues. You can also try compiling with lualatex-dev to see whether a fix is available in the prerelease version. This is a diagnostic step; check the resulting document before relying on it.

Specific questions about the Canvas checker

The Canvas checker says my PDF doesn't have a title.

Make sure your TeX source declares a title either by using the \title command or hyperref's pdftitle tag.

If you open your PDF with Acrobat or another PDF viewer and look at the document properties, do you see a title? If not, recheck the setup steps in Getting started or report it to me (Zach).

Is your document class fully supported by the tagging module? (https://latex3.github.io/tagging-project/tagging-status/) I have been able to recreate the title issue by using amsart (not fully supported!) instead of article.

The Canvas checker complains that my document includes tables without headers.

The Overleaf sandbox (https://www.overleaf.com/9788831262nxxjbmhtwczd#b5bb98) includes examples of how to tag header rows/columns. For example, this marks the first row of a table as its header row: 

\begin{center}
\tagpdfsetup{table/header-rows={1}} % applies to tables later in this group
\begin{tabular}{lcc}
  Problem & Points & Due \\
  1       & 10     & Monday \\
  2       & 15     & Wednesday \\
\end{tabular}
\end{center}

If the first column holds the headers instead, use \tagpdfsetup{table/header-columns={1}}.

More extensive documentation is available here: https://texdoc.org/serve/latex-lab-table/0

Or reach out to me.

Figures and alternative text

Give figures that convey information an appropriate text description. With tagging enabled, the LaTeX Project’s graphics-tagging examples show how to attach alternative text using \includegraphics[alt={Description of the figure}]{filename} and mark decorative graphics with artifact. For complex mathematical diagrams, also provide the detail students need in the surrounding text.

The Canvas checker complains about the section headings in my document.

First, make sure that you are using semantic commands like \section for document structure. It is not enough, for example, to simply make text larger with \Large.

If you have a long document, the problem might be that you are skipping heading levels, for example using \subsection without a parent \section. Which command is the top level depends on the document class: in article, \section is the top level and needs no \chapter; in book and report, \chapter is.

Finally, check that you are not loading packages that are not fully compatible with the tagging module: https://latex3.github.io/tagging-project/tagging-status/

And feel free to reach out to me with questions!

Why does Ally want headings in a problem set?

Ally’s accessibility checklist flags PDFs of at least three pages that have no headings. For a six-page graduate problem set with 30 problems, you might create meaningful groups like these: 

\section*{Problems 1–10}
% Problems 1–10 go here.

\section*{Problems 11–20}
% Problems 11–20 go here.

\section*{Problems 21–30}
% Problems 21–30 go here.

Semantic headings improve navigation for students using screen readers and should address this particular checker finding when correctly tagged. Choose headings that help readers understand the organization; a higher score alone does not establish accessibility.

If I have non-compliant files stored on a Canvas page, but they are not visible to students, will this affect my course's accessibility score?

Yes. Ally scans all content in Canvas Files, including files students cannot see, so you should not use Canvas to store non-compliant files not meant for students. See the explanation in the Ally section. For university guidance, consult UNL’s Canvas and Ally FAQ.

Beamer and slides

The LaTeX tagging project does not support (nor intend to support) the beamer class. Instead, use ltx-talk, a newer class with beamer-like functionality that generates tagged PDFs. It requires LaTeX 2025-11-01 or later.

I have created many slides with ltx-talk. The basic overlay functionality of beamer is implemented, very similarly to how beamer does it, but don’t expect fine control over the appearance of your slides or bells & whistles. For example, I don’t think navigation buttons are implemented (or will be at all?). Some examples are available in the Overleaf project and in the repository folder (Accessibility). I will add more guidance here eventually; for now, contact me with questions.

Note that PowerPoint is also not recommended for producing accessible math output.

Slides for large, convened service courses are handled centrally. If you are concerned about generating compliant slides for another course, please reach out to me (Zach).

LaTeX example and reusable code

MathML and math/alt/use: an Ally compromise

The math/alt/use option in my templates is a compromise for Ally, not an ideal accessibility setting. The Getting started setup includes this line in \DocumentMetadata: 

tagging-setup={math/setup=mathml-SE, math/alt/use}

math/setup=mathml-SE represents formulas using MathML structure elements in the PDF 2.0 structure tree. math/alt/use additionally supplies a flat alt-text string for each formula. In readers and assistive technology that support embedded MathML, structured mathematics can be navigated rather than only read as a flat string. The LaTeX Project’s math-tagging example explicitly advises against the alt-text option.

In our Canvas Ally testing, the checker does not recognize the embedded MathML adequately and can give a low score when formula alt text is absent. That is why my templates include it. A better Ally score does not establish that the formula is easier to use with a screen reader.

If a student uses a screen reader, omitting math/alt/use may give them better results. Discuss and test the document with the student using their PDF reader and assistive tools, and contact me for help finding a good solution. Keep MathML tagging enabled when removing the extra alt-text option: 

tagging-setup={math/setup=mathml-SE}

I have explained the embedded MathML issue to ITS colleagues who are in touch with Ally, and they have been sympathetic. I do not have confirmation of Ally’s plans or a timeline for full PDF 2.0 support.

PDF version and standards

The current setup uses tagging=on; it does not need the older testphase=latest setting. Overleaf recommends pdfstandard=ua-2, the PDF/UA-2 accessibility target, which supports MathML in PDF 2.0. Selecting a target does not by itself certify the document’s accessibility.

The separate pdfstandard=a-4 setting targets PDF/A-4, an archival standard. It is omitted here because long-term archival conformance is a separate requirement from accessible course materials.

The examples explicitly set pdfversion=2.0 for clarity; current LaTeX metadata guidance states that PDF 2.0 is also the default. PDF/UA-2 and the MathML structure-element approach used here belong to the PDF 2.0 workflow; switching to PDF 1.7 would require a different approach, not just changing a version number.

Ally’s incomplete recognition of embedded MathML does not mean the document is inaccessible. Keep the structured mathematics and see the formula alt-text compromise above. Test with the PDF reader and assistive tools the student uses rather than choosing a format solely for Ally’s score.

Full example: tagged-pdf-simple.tex

This short problem set uses LuaLaTeX, the tagging module, MathML, theorem environments, and hyperref metadata. It uses the same metadata block as Getting started, including the math/alt/use compromise. Change the title, author, date, and pdftitle before using it.

Show the full source of tagged-pdf-simple.tex 
% tagged-pdf-simple.tex
% Compile with LuaLaTeX, using TeX Live 2026 or later.
\DocumentMetadata{
  lang = en-US,
  pdfversion = 2.0,
  tagging = on,
  pdfstandard = ua-2,
  tagging-setup = {math/setup=mathml-SE, math/alt/use}
}
\documentclass[reqno, 11pt]{article}

\usepackage{amsmath}
\usepackage{amsthm}
\usepackage{unicode-math} % load after amsmath
\usepackage[margin=1.6in]{geometry}

\usepackage{xcolor}
\definecolor{newblue}{rgb}{0,0,.6}

\theoremstyle{definition}
\newtheorem{thm}{Theorem}
\newtheorem{cor}[thm]{Corollary}
\newtheorem{prob}{Problem}
\newtheorem*{solution*}{Solution}

% Change the title, author, and date, and keep pdftitle below in sync with \title.
\title{Math 450, Problem Set 7}
\author{Zach Norwood}
\date{Due Thursday 11 April 2024}

\usepackage{hyperref}
\hypersetup{
  colorlinks = true,
  citecolor = newblue,
  linkcolor = newblue,
  urlcolor = newblue,
  pdftitle = {Math 450, Problem Set 7},
  pdfauthor = {Zach Norwood}
}

\newenvironment{hint}
  {\begin{small}(\emph{Hint:}}
  {\unskip)\end{small}}

\newcommand{\defem}{\textbf}
% unicode-math sets up its symbols at \begin{document}, so redefine \phi there.
\AtBeginDocument{\renewcommand{\phi}{\varphi}}
\newcommand{\C}{\mathbf{C}}
\newcommand{\R}{\mathbf{R}}
\newcommand{\Q}{\mathbf{Q}}
\newcommand{\Z}{\mathbf{Z}}
\newcommand{\N}{\mathbf{N}}

\begin{document}

\maketitle

\begin{prob}
Give a proof by induction of the following identity, proved by other means in class.
\[
  \sum_{k=0}^n c(n,k) x^k = x^{(n)}.
\]
\end{prob}

\begin{prob}
Recall from Worksheet~7 that the sequence of numbers $B_n$, $n \in \N$, is defined by the
recurrence
\[
  B_0 = 1, \quad \sum_{k=0}^n \binom{n+1}{k} B_k = 0,
\]
and has egf $f(x) = \frac{x}{e^x-1}$.
\begin{enumerate}
\item
What is the solution to the following similar recurrence?
\[
  c_0 = 1, \quad \sum_{0 \le k \le n} \binom{n}{k} c_k = 0
\]
\item
Show that $B_n = 0$ for all odd $n \ge 3$.
\begin{hint}
One approach would begin by showing that $f(x) + x/2$ is an even function.
\end{hint}
\end{enumerate}
\end{prob}

\end{document}

Canvas and Ally scores

Ally is the accessibility auto-checker used in Canvas. Its reports can help identify problems (and are probably being looked at carefully by administrators!), but a perfect Ally score is neither sufficient nor necessary for accessibility. (Goodhart’s Law comes to mind: “When a measure becomes a target, it ceases to be a good measure.”)

What does a course score average?

Anthology’s administrator FAQ describes the course accessibility score as the simple average of the scores of all items in the course.

For example, suppose the scored items are:

  • One 200-page lecture-notes PDF scoring 50%.
  • Twenty short quiz files, each scoring 100%.

The item average is (50 + 20 × 100) ÷ 21 ≈ 97.6%. That high overall score can conceal a problem with the course’s major reference.

Conversely, many small, low-scoring items can pull the average down even if they are rarely used or peripheral to learning. Their barriers still matter, but the average alone does not show their instructional importance.

How should we interpret a department score?

Our best guess from publicly available information is that the department score is a simple item average. This means that, perversely, if we have a 1000-student calculus course with 50 scored items and a 15-student advanced course with 200 scored items, the small course will count 4x as much to the department score.

Do unpublished or instructor-only files count?

Yes: Ally scans all content in Canvas Files. Anthology explicitly confirms this in its Canvas administrator FAQ. Unpublishing a file or preventing students from viewing it does not exclude it from scanning.

For example, inaccessible instructor versions of slides stored alongside accessible student versions can lower the course score, even when students cannot access the instructor versions. Store instructor-only working materials outside Canvas Files when they do not need to be there. Distinguish those materials from student-facing content when interpreting a report.

Try predicting a PDF’s Ally score before uploading

pdfcheck on GitHub is an unofficial, very early alpha command-line tool I vibecoded to estimate a PDF’s Ally issues and score without uploading it to Canvas. It is not endorsed by Anthology.

Its README explains PDF checks for tagging, title, language, heading hierarchy, figure alternative text, table headers, encryption, and parsing, plus a provisional contrast heuristic. It describes two modes: 

pdfcheck --canvas handout.pdf
pdfcheck --full handout.pdf
  • --canvas predicts Ally issue codes and estimates a score.
  • --full adds broader checks and a manual-review checklist.

Rendering-dependent checks are currently skipped, and the README lists additional limitations. Treat the results as preliminary troubleshooting help, not a guaranteed Ally score or accessibility certification.

Prioritize usable mathematics over a perfect score. UNL’s FAQ notes a known Ally issue recognizing PDF 2.0 documents containing MathML and advises choosing the more accessible document. It also explains that a 100% Ally score does not guarantee full accessibility.

HTML and alternatives to LaTeX

Under construction.

I want to convert small documents. What do I do?

You have at least three options:

  1. You can use LaTeX syntax to produce math directly in a Canvas page: try \(…\) for in-line math or $$...$$ for displayed math.
  2. The goal of the LaTeX Tagging Project (described more in Getting started) is to use LaTeX to produce accessible ‘tagged’ PDFs. (These contain a hidden structure tree that records headings, lists, tables, and math, the math as MathML, so that screen readers can present the document properly.) You will need to update your TeX distribution in order to use this, and note that many LaTeX packages and classes are unsupported. It is not yet clear to me whether there is a material difference in accessible PDF vs HTML for students who use screenreaders; that requires more testing. You can try this out by playing in this Overleaf sandbox.
  3. Various tools exist to translate LaTeX source into HTML. (In most cases mathematical formulas are converted to MathML.) For example, LaTeXML is what the arXiv has been using to generate HTML versions of articles. Example.

Handwritten content

Under construction.

Handwritten content, either scanned or composed on a tablet, will not meet accessibility standards without some effort. (Someone, either human or machine, needs to convert the handwriting into text that a screen-reader can understand! And, as always, the math needs to be in an accessible format like MathML.)

AI tools have recently become much more useful for converting handwritten materials, but beware their tendency to edit and paraphrase instead of only transcribing. Check the transcription against the original, including every formula.
